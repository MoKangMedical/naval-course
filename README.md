# 纳瓦尔通识课

> Naval Ravikant 通识课程 · 10 阶段 100 课 · 财富、判断力、幸福与哲学

## 📖 课程简介

基于硅谷投资人、哲学家 **纳瓦尔·拉维坎特（Naval Ravikant）** 的全部公开资料——推文、播客、采访和《纳瓦尔宝典》——系统构建的完整知识体系。

纳瓦尔一生只研究两个问题：**如何致富（不靠运气）** 和 **如何获得幸福**。本课程把这两个问题拆解为 100 门课，从财富创造到东西方哲学。

## 🗂️ 课程结构（10 阶段）

| 阶段 | 主题 | 核心内容 |
|------|------|---------|
| 1 | 财富创造基础 | 财富本质、专长、杠杆 |
| 2 | 判断力与决策 | 清晰思考、心智模型、认知偏差 |
| 3 | 幸福与内在平静 | 减少欲望、冥想、活在当下 |
| 4 | 自我修炼 | 健康、习惯、时间管理 |
| 5 | 科技与创业 | 从 0 到 1、增长、天使投资 |
| 6 | 经济学思维 | 微观、宏观、博弈论 |
| 7 | 投资智慧 | 价值投资、资产配置、风险管理 |
| 8 | 阅读与学习 | 元学习、知识管理、终身学习 |
| 9 | 关系与自由 | 长期关系、信任、自由 |
| 10 | 东西方哲学融合 | 斯多葛、佛教、道家 |
